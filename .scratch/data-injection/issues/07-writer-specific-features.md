# 07 — 文字作者专属功能：书籍+章节+手稿

**What to build:** 为5个文字作者创建书籍、章节和手稿数据，演示文字创作全流程。

**Blocked by:** 04-works-upload-management

**Status:** ready-for-agent

## 背景
文字作者是6种创作者类型之一，有专属的书籍管理功能。

## 数据规模
- 书籍：5本（每本书10-30章）
- 章节：25个（每本书5章示例）
- 手稿：15个（每本书3个版本）
- 文章：20篇（独立于书籍）

## 书籍类型分布
| 类型 | 数量 | 示例标题 |
|-----|------|---------|
| 小说 | 2 | 《星辰大海的旅程》《时光倒流的五分钟》 |
| 散文 | 1 | 《云端之下的秘密》 |
| 诗歌 | 1 | 《回声谷》 |
| 学术 | 1 | 《月光编织者》 |

## 验收标准
- [ ] 5本书籍全部创建，包含封面、ISBN、出版社
- [ ] 每本书至少5个章节，章节按顺序编号
- [ ] 章节包含正文内容（≥1000字）
- [ ] 手稿版本管理正常（draft→revising→final）
- [ ] 文章可独立创建和发布
- [ ] 书籍状态流转：writing→published→archived

## API端点
- POST /api/writer/books — 创建书籍
- GET /api/writer/books — 书籍列表
- POST /api/writer/articles — 创建文章
- GET /api/writer/stats — 作者统计
