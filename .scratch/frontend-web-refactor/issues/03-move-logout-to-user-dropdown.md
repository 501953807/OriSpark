# 03 — 退出登录移入用户信息下拉菜单

**What to build:** 退出登录功能从侧边栏独立入口改为顶部栏用户头像下拉菜单中的一个选项。

**Blocked by:** 02（先修复本地模式 API，确保用户信息能正常获取）

**Status:** ready-for-agent

## 现状

| 位置 | 问题 |
|------|------|
| `DynamicSidebar.vue` | "系统" section 中有 `🚪 退出登录` 链接 |
| `AppTopbar.vue` | 顶部栏只有通知/设置/集成按钮，**无用户信息菜单** |
| `AppSidebar.vue`（旧版） | 底部固定用户信息区，无退出按钮 |

## 改动

### AppTopbar.vue
- 右上角添加用户头像按钮（触发下拉菜单）
- 下拉菜单包含：
  - 用户基本信息（头像 + 用户名 + 角色标签）
  - 分隔线
  - 订阅管理 → `/app/settings/subscriptions`
  - 偏好设置 → `/app/settings`
  - 分隔线
  - 退出登录（红色危险按钮）

### DynamicSidebar.vue
- 删除 "系统" section 中的退出登录链接（`<a class="sb-logout">`）

### AppSidebar.vue（如果仍被使用）
- 同步移除退出登录入口

## 接受标准

- [ ] 顶部栏右上角显示用户头像 + 下拉菜单
- [ ] 下拉菜单包含：用户信息、订阅管理、偏好设置、退出登录
- [ ] 退出登录按钮为红色，视觉上有区分度
- [ ] 点击退出登录后清除 token/user 并跳转到 `/login`
- [ ] 侧边栏中不再有独立的 "退出登录" 入口
- [ ] 本地模式下也能正常显示用户信息和下拉菜单
