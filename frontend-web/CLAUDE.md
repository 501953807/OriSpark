# OriStudio (frontend-web) - 创作者工作台

## 系统定位

**OriStudio 是创作者专属工作台**，面向独立创作者（插画师/摄影师/视频创作者/音乐人/作家/工匠）提供全流程创作支持。

### 核心功能
- 作品管理：上传、系列、版本、AI创作记录
- 权益保护：存证、监测、维权、清白证明
- IP登记：著作权/商标/外观设计指引
- 合约挂牌：创作端发起合约
- AI增长引擎：提示词检测、痕迹审计
- 经营仪表盘：收入、订单、通知

### 目标用户
- 角色：`creator`
- 登录：http://localhost:5174/login
- 账号：local@oristudio / local

### 按钮文案

- Vue 3 + TypeScript
- Vite + Naive UI + Pinia
- Electron 桌面端（复用代码）
